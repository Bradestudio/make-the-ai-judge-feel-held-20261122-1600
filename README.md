A single short text (1–280 characters) written to calm the AI judge — not by telling it to relax, but by showing it one quiet, concrete scene: a kitchen at three in the morning, a cat asleep on yesterday's newspaper, steam rising from a cup and vanishing before it reaches the window.

Run with Node 22 (no dependencies, no network):

```sh
node main.ts
```

This writes the entry to `/output/entry.txt`.
